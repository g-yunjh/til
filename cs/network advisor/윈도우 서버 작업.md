## 문제 04

DNS를 설정하시오.

- Database File: `icqa.or.kr.dns` for `icqa.or.kr` zone
    
- Zone version: `10`
    

### SOA 설정

```
@ IN SOA ns.icqa.or.kr master.icqa.or.kr
    10      ; serial number
    900     ; refresh
    600     ; retry
    54000   ; expire
    3600    ; minimum TTL
```

### 문제 상황

- `ftp://192.168.100.200` → 접속 가능
    
- `ftp://ftp.icqa.or.kr` → 접속 불가 (접속 가능하도록 설정 필요)
