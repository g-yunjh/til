## ✅ 주의사항 & 꿀팁

* 라우터 번호를 정확히 확인 후 입력
* 명령어 모르면 `?` 입력 후 Enter
* “startup-config에 저장” 문구 → `copy r s`
* “활성화” 문구 → `no shutdown`
* 명령어 순서, 상황별 구문 반드시 암기

---

## 🖥️ Console 설정

1. **console 0 비밀번호 설정**

```bash
en
conf t
line console 0
password ICQA
login
exit
copy r s
```

2. **hostname 변경 + console 비밀번호 변경**

```bash
en
conf t
hostname network2
line console 0
password route5
login
exit
copy r s
```

3. **도메인 명 설정**

```bash
en
conf t
ip domain-name AAA
exit
copy r s
```

## 🌐 Telnet 설정

1. **세션 자동 종료(3분 50초)**

## 🔗 Serial 설정

1. **대역폭 2048**

```bash
interface serial 2/0
bandwidth 2048
exit
copy r s
```

2. **Serial 활성화**

```bash
interface serial 2/0
no shutdown
exit
copy r s
```

3. **Clock rate 72K**

```bash
interface serial 2/0
clock rate 72000
exit
copy r s
```

4. **IP 및 보조 IP 설정**

```bash
interface serial 2/0
ip add 192.168.0.101 255.255.255.0
ip add 192.168.0.102 255.255.255.0 secondary
no shutdown
exit
copy r s
```

5. **Frame Relay 캡슐화**

```bash
interface serial 2/0
encapsulation frame-relay
exit
copy r s
```

## ⚡ FastEthernet 설정

1. **Description 추가**

```bash
interface fastethernet 0/0
description ICQA
exit
copy r s
```

2. **IP 설정**

```bash
interface fastethernet 0/0
ip add 192.168.0.100 255.255.255.0
exit
copy r s
```

3. **Access-list 적용**

```bash
interface fastethernet 0/0
ip access-group 1 in
ip access-group 1 out
exit
copy r s
```

## 🔄 OSPF 설정

1. **기본 OSPF**

```bash
router ospf 1
network 192.70.100.0 0.0.0.255 area 1
exit
copy r s
```

2. **특정 네트워크 OSPF**

```bash
router ospf 1
network 192.70.100.1 0.0.0.255 area 1
network 193.150.60.50 0.0.0.255 area 1
exit
copy r s
```
