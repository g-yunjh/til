- 가장 간단하게 연결하는 노드포트
	- **NodePort**는 클러스터 외부에서 특정 노드의 IP와 포트를 통해 파드에 접근할 수 있도록 해주는 서비스입니다.

- 사용 목적별로 연결하는 인그레스
	- **Ingress**는 HTTP/HTTPS 트래픽을 라우팅하는 역할을 합니다. 도메인 기반 또는 경로 기반으로 트래픽을 분기시킬 수 있습니다.

- 클라우드에서 쉽게 구성 가능한 로드밸런서
	- **LoadBalancer** 타입의 서비스는 클라우드 환경에서 외부 로드밸런서를 자동으로 프로비저닝해 파드에 접근할 수 있도록 해줍니다.

- 온프레미스에서 로드밸런서를 제공하는 MetalLB
	- MetalLB는 온프레미스 환경에서 로드밸런서를 제공하는 오픈소스 솔루션으로, L2/L3 모드를 지원합니다.

- 부하에 따라 자동으로 파드 수를 조절하는 HPA
	- **Horizontal Pod Autoscaler(HPA)**는 CPU 사용량 등을 기준으로 파드의 수를 자동으로 확장하거나 축소합니다.
