### 1. 그라파나로 모니터링 데이터 시각화하기
- 헬름으로 그라파나 설치하기  
	- Prometheus와 함께 Helm 차트로 자동 설치되며, 별도로 배포할 수도 있습니다.  
	- 단독 설치 예시:  
	```bash
	helm repo add grafana https://grafana.github.io/helm-charts
	helm repo update
	helm install grafana grafana/grafana -n monitoring --create-namespace
	```

- 프로메테우스를 데이터 소스로 구성하기  
	- Grafana 웹 UI 접속:  
	```bash
	kubectl port-forward svc/grafana 3000:80 -n monitoring
	```
	- 기본 ID: `admin`, PW: `prom-operator`  
	- **Configuration > Data Sources** 메뉴에서 Prometheus URL을 설정해 연결합니다.

- 노드 메트릭 데이터 시각화하기  
	- Grafana의 `Node Exporter Full` 대시보드를 가져오거나, 직접 쿼리하여 CPU, 메모리 사용률을 시각화합니다.  
	- 예:  
	```promql
	node_cpu_seconds_total{mode="idle"}
	```

- 파드 메트릭 데이터 시각화하기  
	- 파드 단위의 CPU/메모리 사용량을 시각화해, 워크로드의 자원 사용량을 모니터링합니다.  
	- 예:  
	```promql
	sum(container_memory_usage_bytes{namespace="default"}) by (pod)
	```

### 2. 좀 더 견고한 모니터링 환경 만들기
- 얼럿매니저로 이상 신호 감지하고 알려주기  
	- Alertmanager는 Prometheus의 Alert 룰을 받아 Slack, 이메일, 웹훅 등으로 경보를 전송합니다.  
	- Helm 설치 시 Alertmanager가 함께 배포되며, 기본 Alert 룰이 포함됩니다.  
	- 예시 Alert 룰:  
	```yaml
	alerts:
	  - alert: HighCPUUsage
	    expr: avg(rate(container_cpu_usage_seconds_total[1m])) by (pod) > 0.9
	    for: 2m
	    labels:
	      severity: critical
	    annotations:
	      description: "Pod {{ $labels.pod }} CPU 사용률이 90%를 초과했습니다!"
	```

- 내가 만든 대시보드 공유하기  
	- Grafana의 **Dashboard > Share** 메뉴를 통해 JSON 형식으로 대시보드를 내보내거나 공유할 수 있습니다.  
	- 공유 URL을 만들어 팀원들과 실시간으로 대시보드를 확인할 수도 있습니다.

- 다른 사람이 만든 대시보드 가져오기  
	- Grafana의 [Dashboard Repository](https://grafana.com/grafana/dashboards)에서 공개된 대시보드를 가져와 바로 사용할 수 있습니다.  
	- **Import** 메뉴에 Dashboard ID를 입력해 빠르게 설정할 수 있습니다.
