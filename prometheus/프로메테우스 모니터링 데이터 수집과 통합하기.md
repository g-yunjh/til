### 1. 컨테이너 인프라 환경 모니터링 하기
- 모니터링 도구 선택하기  
	- **Prometheus**: 오픈소스 시계열 DB로, 쿠버네티스 환경에서 메트릭 수집과 저장을 담당합니다.  
	- **Grafana**: Prometheus 데이터를 시각화해 대시보드 형태로 보여줍니다.  
	- **Loki**: 로그 수집과 검색에 특화된 도구로, Grafana와 통합됩니다.  
	- **Alertmanager**: Prometheus의 알림(이상 감지)을 Slack, 이메일 등으로 전송해줍니다.

- 쿠버네티스 환경에 적합한 모니터링 데이터 수집 방법  
	- 쿠버네티스는 컨테이너, 노드, 클러스터 상태를 메트릭으로 제공합니다.  
	- Prometheus의 **Service Discovery**를 통해 쿠버네티스 API를 조회하고, 자동으로 메트릭을 수집합니다.  
	- Exporter를 활용하면 노드나 파드의 세부 메트릭까지 쉽게 수집할 수 있습니다.

### 2. 프로메테우스 모니터링 데이터 수집과 통합하기
- 헬름으로 프로메테우스 설치하기  
	- Helm 차트를 사용하면 Prometheus와 Grafana를 한 번에 설치할 수 있습니다.  
	- 예시:  
	```bash
	helm repo add prometheus-community https://prometheus-community.github.io/helm-charts
	helm repo update
	helm install kube-prometheus-stack prometheus-community/kube-prometheus-stack -n monitoring --create-namespace
	```

- 프로메테우스의 웹 UI 다루기  
	- 설치 후:  
	```bash
	kubectl port-forward svc/kube-prometheus-stack-prometheus 9090:9090 -n monitoring
	```
	- 웹 UI (http://localhost:9090)에서 현재 수집된 메트릭, Targets, Alert, Rule을 확인할 수 있습니다.

- 서비스 디스커버리로 수집 대상 가져오기  
	- Prometheus는 `kubernetes_sd_config`를 통해 자동으로 파드, 서비스, 엔드포인트를 수집 대상으로 인식합니다.  
	- Helm 차트로 설치된 경우, 기본적으로 쿠버네티스 리소스를 감지하도록 설정되어 있습니다.

- 노드 익스포터로 쿠버네티스 노드 메트릭 수집하기  
	- **node-exporter**는 각 노드의 CPU, 메모리, 디스크, 네트워크 메트릭을 수집합니다.  
	- Helm 차트의 일부로 자동 설치되며, Prometheus가 `/metrics` 엔드포인트를 수집하도록 구성됩니다.

- 쿠버 스테이트 메트릭으로 쿠버네티스 클러스터 메트릭 수집하기  
	- **kube-state-metrics**는 클러스터 상태(파드 상태, 레플리카셋 상태 등)를 메트릭으로 제공합니다.  
	- Helm으로 함께 설치되며, Prometheus는 이 데이터를 통해 리소스의 상태와 변화를 감지합니다.
