### 🔍 이미지 검색 및 확인
- `docker search <검색어>` : 이미지 검색
- `docker images` : 이미지 목록 확인

---

### 📦 컨테이너 목록 확인
- `docker ps -a` : 컨테이너 목록 확인 (중지된 컨테이너도 표시됨)
- 옵션:  
  - `-a` : 중지된 컨테이너도 표시  
  - `-f id=<컨테이너 id>` : 특정 컨테이너 id로 필터링

---

### 🔽 레지스트리로부터 이미지 다운
- `docker pull <이미지이름>` : 이미지 다운로드

---

### 🚀 컨테이너 만들기
- `docker run [컨테이너이름] <이미지이름>`  
- 한 이미지로 여러 개의 컨테이너를 만들 수 있음

#### 주요 옵션:
- `--name <이름>` : 컨테이너 이름
- `-p <host포트>:<container포트>` : 포트 연결
- `-v <host경로>:<container경로>` : 디렉토리 파일 공유
- `-d` : 컨테이너를 백그라운드에서 구동
- `--restart always` : 컨테이너를 자동으로 시작  
  가상 머신을 중지했다가 다시 실행해도 컨테이너가 기존 상태를 이어감

---

### 🛑 컨테이너 제어
- `docker stop <컨테이너 이름>` : 컨테이너 중지
- `docker start <컨테이너 이름>` : 중지되었던 컨테이너 시작
- `docker logs -f <컨테이너 이름>` : 실시간 로그 출력

---

### 🗑️ 컨테이너 및 이미지 삭제
- `docker rm <컨테이너 이름>` : 컨테이너 삭제
- `docker rm -f <컨테이너 이름>` : 컨테이너 강제 삭제
- `docker rmi <이미지 이름>` : 이미지 삭제

---

### 🐚 컨테이너 접속
- `docker exec -it <컨테이너 이름> /bin/bash` : bash로 컨테이너 접속
