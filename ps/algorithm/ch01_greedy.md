# Ch01. 그리디 알고리즘

## 1. 개념 요약
- **그리디(Greedy)**: 현재 상황에서 당장 가장 좋은 선택을 반복.
- 항상 최적해 보장 ❌ → **정당성 분석 필수**.
- 코딩 테스트: 문제 구조 분석 후 최적해 가능 여부 판단.

## 2. 핵심 아이디어
1. 각 단계에서 최적이라고 생각되는 선택 수행.
2. 구조적으로 부분 최적이 전체 최적으로 이어지는 경우 강력 (예: 화폐 단위가 배수 관계).
3. 설계는 간단하지만, 조건 불충분 시 오답 가능.

## 3. 대표 예시
### (1) 거스름돈 문제
- 큰 화폐 단위부터 차례대로 거슬러 줌.
- 시간 복잡도: O(K) (화폐 종류 K)

### (2) 1이 될 때까지
- N % K == 0 → N /= K  
- else → N -= 1

### (3) 곱하기 혹은 더하기
- 0 또는 1 포함 → 더하기  
- 둘 다 ≥ 2 → 곱하기

## 4. 구현(Implementation) 개념
- 머릿속 알고리즘 → 코드로 변환.
- 시뮬레이션, 완전 탐색, 문자열 처리, 2차원 배열 활용 빈출.

### 구현 예시
1. **상하좌우**: 이동 명령에 따른 좌표 시뮬레이션.
2. **시각**: 가능한 모든 경우를 완전 탐색.

## 5. 파이썬 코드
```python
# 거스름돈 문제
coins = [500, 100, 50, 10]
n = int(input())
cnt = 0
for coin in coins:
    cnt += n // coin
    n %= coin
print(cnt)

# 상하좌우 문제
n = int(input())
plans = input().split()
x, y = 1, 1
dx = [0, 0, -1, 1]
dy = [-1, 1, 0, 0]
moves = ['L', 'R', 'U', 'D']

for plan in plans:
    for i in range(4):
        if plan == moves[i]:
            nx = x + dx[i]
            ny = y + dy[i]
            if 1 <= nx <= n and 1 <= ny <= n:
                x, y = nx, ny
print(x, y)
```
