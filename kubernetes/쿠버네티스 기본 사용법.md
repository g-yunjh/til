- 파드를 생성하는 방법
	- `kubectl run` 명령어 또는 YAML 파일로 파드를 생성할 수 있습니다.
	- 예:  
	```bash
	kubectl run nginx --image=nginx --restart=Never
	```
	또는  
	```yaml
	apiVersion: v1
	kind: Pod
	metadata:
	  name: nginx
	spec:
	  containers:
	  - name: nginx
	    image: nginx
	```

- 오브젝트란
	- 쿠버네티스에서 관리하는 모든 리소스를 **오브젝트**라고 부릅니다. 파드, 서비스, 디플로이먼트, 컨피그맵 등이 오브젝트입니다.

- 레플리카셋으로 파드 수 관리하기
	- **ReplicaSet**은 파드의 복제본 수를 보장하는 컨트롤러입니다. 선언된 파드 수가 유지되도록 합니다.

- 스펙을 지정해 오브젝트 생성하기
	- YAML이나 JSON 파일로 오브젝트의 스펙을 작성하고, `kubectl apply`로 배포합니다.
	- 선언형 방식으로 관리가 용이합니다.

- apply로 오브젝트 생성하고 관리하기
	- `kubectl apply -f <file>.yaml` 명령어를 사용해 오브젝트를 생성·업데이트합니다.
	- 선언형 배포는 기존 오브젝트를 덮어쓰거나 병합해 적용됩니다.

- 파드의 컨테이너 자동 복구 방법
	- 컨트롤러(예: Deployment, ReplicaSet)는 파드가 비정상적으로 종료되면 자동으로 새로운 파드를 생성해 복구합니다.

- 파드의 동작 보증 기능
	- **Liveness Probe**와 **Readiness Probe**를 설정해 파드가 정상적으로 동작하는지 주기적으로 확인하고, 장애를 감지합니다.

- 노드 자원 보호하기
	- **리소스 요청/제한(Resource Request/Limit)**을 설정해 파드가 노드의 CPU나 메모리를 과도하게 점유하지 않도록 합니다.

- 노드 유지보수하기
	- `kubectl cordon`과 `kubectl drain` 명령어로 노드를 안전하게 유지보수 모드로 전환하고, 워크로드를 다른 노드로 이관할 수 있습니다.

- 파드 업데이트하고 복구하기
	- **Deployment** 오브젝트를 사용하면 롤링 업데이트로 무중단 배포를 지원하고, 문제가 발생하면 롤백이 가능합니다.
